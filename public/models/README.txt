Place ici tes modeles 3D personnalises:

1. player.glb  -> ton joueur de foot (Mixamo, Sketchfab, etc.)
2. keeper.glb  -> ton gardien (Mixamo, Sketchfab, etc.)

Format recommande:
- Echelle : 1 unite = 1 metre
- Origine : au sol, entre les pieds
- Orientation : face vers +Z (vers le but)
- Animations requises : "Idle", "Run" (nommees ainsi dans le GLB)

Si ces fichiers sont absents, le jeu utilise automatiquement
le modele "Soldier.glb" officiel de Three.js via CDN.
